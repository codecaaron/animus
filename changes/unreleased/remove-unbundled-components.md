**Vite builds can drop the CSS of components the bundle never ships.** With `stylesheets: 'split'`, the new `removeUnbundledComponents: true` option removes from the stylesheet's files every rule of a component whose definition no output file includes. Such a component can never render, because a dropped definition is the only place its class enters the page. Each changed file is emitted again under the hash of what it now holds. A component `staticCss` declares and the parents of a kept extension stay. A build that also bundles another environment, or that leaves a module external, keeps everything and says why. The build reports how many components it removed; `verbose: 'trace'` lists each one. Off by default, and development ignores it.
