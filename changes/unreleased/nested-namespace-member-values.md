**Nested namespace members passed as values keep their CSS.** A component reached through a nested namespace and used as a value, as in `pick(ui.forms.Input)`, `const Field = ui.forms.Input`, `<Box as={ui.forms.Input} />`, or `pick(forms.Input)` through a named import of the namespace, could render anywhere with any props, but production builds kept only the options its visible renders set. It now keeps every option it declares, at any depth. Only that component opens: the namespace's other components stay pruned, and a type-only use opens nothing.
