**`removeUnbundledComponents` no longer rewrites the rules it keeps.** Trimming a stylesheet reprinted it for Animus's browser targets rather than the ones the build printed it for, so a build whose CSS targets differed lost prefixes it needed and gained others: twenty's documentation sheet lost all 12 `-webkit-backdrop-filter` declarations, which Safari before 18 needs for its blur effects. Removal now cuts the removed rules out of the text the build wrote and reprints nothing, so every rule it keeps stays byte for byte as written. If the trimmed sheet doesn't read as the original less those rules, the file is kept whole and the build says so.
